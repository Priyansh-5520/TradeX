🔑 TradeX Auth Tester

Sign in with Google to get your ID Token for Postman testing

📝 How to use:

Step 0: Replace YOUR_GOOGLE_CLIENT_ID_HERE in this file (line ~79) with your actual Google Client ID.

Step 1: Click "Sign in with Google" above.

Step 2: Copy the token shown below.

Step 3: In Postman, send a POST to http://localhost:5000/api/auth/google with body:
{ "idToken": "PASTE_TOKEN_HERE" }

Step 4: If you get isNewUser: true, send a POST to http://localhost:5000/api/auth/complete-signup with body:
{ "idToken": "PASTE_TOKEN_HERE", "userName": "your_username" }
